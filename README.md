# ☕ Coffee Shop Sales Dashboard

## 📊 Project Overview

**Coffee Shop Sales Dashboard | Excel, Power Query, Pivot Tables**

Analyzed **20,000+ coffee shop transactions** across **3 store locations** to build an interactive **Excel MIS dashboard** for sales performance reporting.

Cleaned and transformed raw data using **Power Query**; created **Pivot Tables, slicers, and charts** to track revenue by store, top products, peak hours, and category-wise sales.

Identified key insights such as **top-performing store**, **best-selling products**, and **peak sales hours (8–10 AM)** to support inventory, staffing, and product decisions.

## 📂 Dataset Overview

### Columns

| Column | Description |
|--------|-------------|
| `transaction_id` | Unique ID for each sale |
| `transaction_date` | Date of sale (MM-DD-YYYY) |
| `transaction_time` | Time of sale (HH:MM:SS) |
| `transaction_qty` | Quantity sold |
| `store_id` | Store identifier |
| `store_location` | Store name (Lower Manhattan, Hell's Kitchen, Astoria) |
| `product_id` | Product identifier |
| `unit_price` | Price per unit |
| `product_category` | Category (Coffee, Tea, Bakery, etc.) |
| `product_type` | Type within category |
| `product_detail` | Specific product name |

### Data Facts

- **Period**: January 2023 – Early 2023
- **Locations**: 3 stores (Lower Manhattan, Hell's Kitchen, Astoria)
- **Categories**: Coffee, Tea, Drinking Chocolate, Bakery, Flavours, Loose Tea, Packaged Chocolate, Coffee Beans, Branded Merchandise

## 📚 Key Insights

- **Best selling product**: Gourmet brewed coffee (Ethiopia)
- **Top store**: Lower Manhattan
- **Peak hours**: 8:00 AM – 10:00 AM
- **Most popular category**: Coffee (with ~60% of sales)
- **Weekend vs Weekday**: Weekend sales are lower than weekdays
